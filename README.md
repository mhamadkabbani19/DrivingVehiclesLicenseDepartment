# DrivingVehiclesLicense

## My first real project.

##### - To open this project :
##### 1. Download sql server.
##### 2. Restore the DVLD database from DVLD.bak backup.
##### 3. Put your connection string in the app configurations in app.config file.
##### 3. Run the project.

##### - If you want to see the Business and Data Access Layer of the project, it's in the DVLD_Business and DVLD_DataAccess files in the project.
